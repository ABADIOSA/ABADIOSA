# 🦅 موقع القلعة الخضراء — النادي الأهلي السعودي

موقع جماهيري متكامل يهتم بكل ما يخص النادي الأهلي السعودي، ويتحدّث **تلقائيًا أول بأول**، مبني بخط النادي الرسمي **Al Ahli Display**.

## ✨ الأقسام والميزات

| القسم | الوصف |
|---|---|
| 🤖 **المساعد الأهلاوي الذكي** | محادثة عربية تعمل في المتصفح على بيانات الموقع الحية: اسأله عن أي لاعب، الهدافين، الترتيب، الإحصائيات، أو اطلب **مقارنة بين لاعبين** أو **توقعًا ذكيًا** لنتيجة المباراة |
| 📰 **الأخبار** | تُجلب تلقائيًا من Google News وتتجدد باستمرار |
| 👕 **الفريق الأول** | التشكيلة الحقيقية **بصور اللاعبين والمدرب**، وشارة أهداف كل لاعب، وفلترة بالمراكز |
| ⚽ **التشكيلة على أرض الملعب** | ملعب تفاعلي يرسم أفضل تشكيلة بثلاث خطط: 4-3-3 · 4-2-3-1 · 3-5-2 |
| ⚖️ **مقارنة اللاعبين** | قارن أي لاعبَين بالخصائص والأهداف مع رسوم بيانية وحكم نهائي |
| 📊 **الإحصائيات والهدافون** | أهداف وصناعة كل لاعب + استحواذ وتسديدات وركنيات — **محسوبة من ملخصات المباريات الرسمية** |
| 📅 **المباريات** | القادمة بعدّاد تنازلي، والنتائج مع **شريط فورم آخر 5 مباريات** |
| 🏅 **الترتيب** | جدول دوري روشن كاملًا بالشعارات مع تمييز صف الأهلي |
| 🏆 **خزانة البطولات** | وفق التقرير النهائي للجنة توثيق تاريخ الكرة السعودية |
| 🗳️ **تصويت الجماهير** | استطلاع تفاعلي بنتائج فورية |
| 🎮 **الألعاب** | اختبار أهلاوي · خمّن اللاعب · **ركلات الجزاء** · لعبة الذاكرة — مع حفظ أفضل نتيجة |
| 🛍️ **المتجر** | منتجات النادي مع روابط المتجر الرسمي |

بالإضافة إلى: **الوضع الليلي** 🌙، **بحث شامل** 🔍، **حركات ظهور** وشريط تقدم القراءة، و**تطبيق ويب (PWA)** قابل للتثبيت ويعمل دون اتصال.

## 🔄 كيف يتحدث الموقع تلقائيًا؟

مصادر البيانات: **واجهة ESPN العامة** (التشكيلة، المباريات، الترتيب، الهدافون، الشعارات)، **ويكيبيديا** (صور اللاعبين والمدرب)، و**Google News RSS** (الأخبار) — بلا أي مفاتيح API.

1. **تحديث مجدول (GitHub Actions):** `.github/workflows/update-news.yml` يشغّل `scripts/update_news.py` و`scripts/update_data.py` **كل 3 ساعات**، فيحدّث ملفات `data/` ويرفعها وينشرها على الموقع تلقائيًا.
2. **تحديث لحظي (المتصفح):** المباريات والترتيب من ESPN والأخبار من Google News، مع الرجوع للنسخة المخزنة عند تعذّر الاتصال، وتجدد تلقائي كل 10 دقائق.
3. **نهاية الموسم:** عندما تفرغ بيانات الموسم الجديد قبل انطلاقه، يرجع الموقع تلقائيًا لعرض أرشيف الموسم المكتمل بدل صفحة فارغة.

## 🚀 التشغيل والنشر

الموقع ثابت بالكامل (HTML/CSS/JS) بلا أي اعتماديات بناء.

```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
```

النشر يتم تلقائيًا على GitHub Pages عبر فرع `gh-pages` مع كل دفعة إلى `main`.
🌐 **الموقع المباشر:** https://abadiosa.github.io/ABADIOSA/

## 🛠️ تعديل البيانات

| الملف | المحتوى |
|---|---|
| `data/players.json` | طبقة الإثراء العربية: الأسماء والتقييمات والنبذ + **`departed`/`signings`** لتصحيح الانتقالات فورًا |
| `data/store.json` | منتجات المتجر والأسعار |
| `data/squad.json` | التشكيلة والصور — **تلقائي** |
| `data/stats.json` | الهدافون وإحصائيات الموسم — **تلقائي** |
| `data/matches_auto.json` | المباريات والنتائج — **تلقائي** |
| `data/standings.json` | ترتيب الدوري — **تلقائي** |
| `data/news.json` | الأخبار — **تلقائي** |

### تصحيح انتقالات اللاعبين
عندما يرحل لاعب أو ينضم آخر قبل أن تحدّث ESPN قوائمها، عدّل `data/players.json`:
```jsonc
"departed": ["Player Name"],          // يُخفى من الموقع فورًا
"signings": [{ "name": "New Player", "position": "FW", ... }]  // يُضاف مع صورته تلقائيًا
```
