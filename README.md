# 📬 TempMailWin — تطبيق بريد مؤقت لويندوز

تطبيق سطح مكتب لويندوز يتيح لك **إنشاء عناوين بريد مؤقتة، واختيار الدومين، واستقبال
الرسائل مباشرة داخل التطبيق** — بواجهة عربية كاملة من اليمين إلى اليسار.

يعمل بمكتبات بايثون القياسية فقط (بلا اعتماديات إجبارية)، ويمكن تحويله إلى ملف
`TempMailWin.exe` واحد.

---

## ✨ المزايا

| الميزة | التفاصيل |
|---|---|
| **اختيار الدومين** | من قائمة دومينات جاهزة، **أو من دومينك الخاص أنت** |
| **اختيار الاسم قبل @** | اكتب ما تريد، أو ولّد اسمًا عشوائيًا بضغطة |
| **عناوين متعددة** | احتفظ بعدة عناوين وبدّل بينها، مع عدّاد للرسائل غير المقروءة |
| **تحديث تلقائي** | يفحص الوارد كل 10 ثوانٍ (قابل للتعديل) مع تنبيه صوتي |
| **نسخ رمز التحقق** | يستخرج رمز OTP من الرسالة ويعرض زر نسخ مباشر |
| **المرفقات** | عرض وتنزيل، مع دعم أسماء الملفات العربية |
| **حجب المتتبّعات** | الصور الخارجية محجوبة افتراضيًا حتى لا يعرف المرسل أنك فتحت الرسالة |
| **مظهر داكن/فاتح** | تبديل فوري، ويُحفظ اختيارك |

## 🚀 التشغيل السريع

**المتطلب الوحيد:** [Python 3.10+](https://www.python.org/downloads/) — وعند التثبيت
فعّل خيار **Add Python to PATH**.

```bat
:: من مجلد المشروع
python run.py
```

أو انقر مرتين على **`run.bat`**.

```bat

```

متصفحك الافتراضي — وكل شيء يعمل كالمعتاد.

## 🌐 اختيار الدومين — طريقتان

### الطريقة الأولى: دومينات جاهزة (بلا أي إعداد)

اختر مزوّدًا من القائمة، ثم اختر الدومين الذي يعجبك:

| المزوّد | ملاحظات |
|---|---|
| **Mail.tm** | صندوق حقيقي، عدة دومينات، يدعم حذف الرسائل والمرفقات |
| **Mail.gw** | نفس المزايا بدومينات مختلفة — بديل جيد عند تعطّل الأول |
| **1SecMail** | عنوان فوري بلا تسجيل، لا يدعم حذف الرسائل، وقد يتوقف أحيانًا |

> هذه الدومينات **عامة ومشتركة**: أي شخص يعرف العنوان يستطيع قراءة رسائله.
> استخدمها للتسجيلات المؤقتة فقط — لا للحسابات المهمة.

### الطريقة الثانية: دومينك الخاص أنت 👑

إذا كنت تملك دومينًا (مثل `example.com`)، تستطيع إنشاء **أي عنوان عليه**:
`shop@example.com`، `test1@example.com`، وهكذا بلا حد.

الفكرة: توجّه كل بريد الدومين إلى صندوق واحد (**catch-all**)، ثم يقرأ التطبيق ذلك
الصندوق عبر **IMAP** ويعرض لك فقط رسائل العنوان الذي تختاره.

#### الخطوة 1 — تفعيل catch-all عبر Cloudflare (مجانًا)

1. أضف دومينك إلى [Cloudflare](https://dash.cloudflare.com) (تغيير خوادم الأسماء NS).
2. من لوحة التحكم افتح **Email › Email Routing** واضغط **Enable** — ستُضاف سجلات
   MX تلقائيًا.
3. في **Destination addresses** أضف بريدك الحقيقي (Gmail مثلًا) وأكّده من رسالة التفعيل.
4. في **Catch-all address** فعّلها، واختر **Action: Send to** ثم بريدك الحقيقي.

الآن أي رسالة إلى `أي-اسم@دومينك` تصل إلى صندوقك الحقيقي.

> بديل لـ Cloudflare: [ImprovMX](https://improvmx.com) يقدّم تحويل catch-all مجاني أيضًا.
> وأي صندوق بريد يدعم IMAP يصلح — ليس Gmail حصرًا.

#### الخطوة 2 — كلمة مرور تطبيق لـ Gmail

Gmail لا يقبل كلمة مرورك العادية عبر IMAP:

1. فعّل **التحقق بخطوتين** من [إعدادات أمان جوجل](https://myaccount.google.com/security).
2. أنشئ **كلمة مرور التطبيقات** من [هنا](https://myaccount.google.com/apppasswords).
3. انسخ الكلمة المكوّنة من 16 حرفًا.
4. تأكد أن **IMAP مفعّل** في Gmail: الإعدادات ← إعادة التوجيه و POP/IMAP.

#### الخطوة 3 — إدخال البيانات في التطبيق

افتح **⚙ الإعدادات ← دومينك الخاص (IMAP)**:

| الحقل | القيمة |
|---|---|
| خادم IMAP | `imap.gmail.com` |
| المنفذ | `993` |
| اسم المستخدم | بريدك الحقيقي |
| كلمة المرور | كلمة مرور التطبيقات (16 حرفًا) |
| مجلد البريد | `INBOX` |
| دوميناتك | `example.com` (وتقدر تضيف أكثر بفاصلة) |
| SSL/TLS | ✅ مفعّل |

اضغط **اختبار الاتصال** للتأكد، ثم **حفظ**.

الآن اختر المزوّد **«دومينك الخاص (IMAP)»**، واكتب أي اسم تريده، واضغط **إنشاء العنوان**.

## 🔒 الأمان والخصوصية

- **الخادم محلي بالكامل**: يستمع على `127.0.0.1` بمنفذ عشوائي، ولا يقبل أي اتصال
  من خارج جهازك.
- **رمز جلسة سرّي**: كل طلب يتطلب رمزًا يُولَّد عند التشغيل ويُحقن في الصفحة، فلا
  يستطيع أي موقع مفتوح في متصفحك قراءة بريدك عبر `localhost`.
- **كلمة مرور IMAP مشفّرة**: تُحفظ عبر **DPAPI** المرتبط بحساب ويندوز الخاص بك،
  فلا يفكّها مستخدم آخر على نفس الجهاز.
- **عرض الرسائل معزول**: محتوى كل رسالة يُعرض داخل إطار `sandbox` بسياسة محتوى
  صارمة — **لا تعمل أي سكربتات**، والصور الخارجية محجوبة حتى تطلبها بنفسك.
- **لا تتبّع**: التطبيق لا يرسل أي بيانات لأي جهة عدا مزوّد البريد الذي تختاره.

### أين تُحفظ بياناتك؟

```
%APPDATA%\TempMailWin\
├── settings.json    الإعدادات (كلمة مرور IMAP مشفّرة)
└── accounts.json    عناوينك المحفوظة
```

لحذف كل شيء: احذف هذا المجلد.

## 🧩 بنية المشروع

```
tempmail/
├── app.py                    نقطة التشغيل وفتح النافذة
├── server.py                 الخادم المحلي والواجهة البرمجية
├── store.py                  حفظ الإعدادات والعناوين
├── secrets_store.py          تشفير كلمات المرور (DPAPI)
├── http_client.py            عميل HTTP بمحدّد معدّل وإعادة محاولة
├── paths.py                  مسارات البيانات والموارد
├── providers/
│   ├── base.py               الواجهة المشتركة للمزوّدات
│   ├── mailtm.py             Mail.tm و Mail.gw
│   ├── onesecmail.py         1SecMail
│   └── imap_catchall.py      دومينك الخاص عبر IMAP
└── web/                      الواجهة (HTML/CSS/JS بلا مكتبات)
```

### إضافة مزوّد جديد

اشتق صنفًا من `Provider` في `providers/base.py`، نفّذ `list_domains` و
`create_account` و `list_messages` و `get_message`، ثم أضفه في
`providers/__init__.py`. الواجهة تلتقطه تلقائيًا.

## 🛠️ حل المشاكل

| المشكلة | الحل |
|---|---|
| «تعذّر جلب الدومينات» | تحقّق من الإنترنت، أو جرّب مزوّدًا آخر (Mail.gw مثلًا) |
| «فشل تسجيل الدخول إلى صندوق البريد» | استخدم **كلمة مرور التطبيقات** لا كلمة مرورك العادية، وتأكد أن IMAP مفعّل |
| لا تصل رسائل على دوميني | تأكد أن **catch-all** مفعّلة وأن سجلات MX صحيحة؛ جرّب إرسال رسالة تجريبية وتأكد من وصولها لصندوقك الحقيقي أولًا |
| «هذا العنوان محجوز» | بعض المزوّدات تحجز أسماء شائعة — جرّب اسمًا آخر |
| التطبيق لا يُغلق | اضغط زر **⏻** في أسفل الشريط الجانبي |
| الصور لا تظهر في الرسالة | محجوبة عمدًا — اضغط **«عرض الصور»** أو فعّلها من الإعدادات |

## ⚠️ تنبيه مهم

البريد المؤقت على الدومينات العامة **غير آمن للحسابات المهمة**: لا تستخدمه للبنوك
أو الحسابات الحكومية أو أي شيء لا تريد فقدانه. استخدمه للتجارب والتسجيلات المؤقتة.
لخصوصية حقيقية، استخدم **دومينك الخاص** عبر الطريقة الثانية أعلاه.
