# 🦅 موقع القلعة الخضراء — النادي الأهلي السعودي

موقع جماهيري متكامل يهتم بكل ما يخص النادي الأهلي السعودي، ويتحدّث **تلقائيًا أول بأول**.

## ✨ الأقسام

- **📰 الأخبار** — تُجلب آخر أخبار النادي تلقائيًا من مصادر إخبارية (Google News) وتتجدد باستمرار.
- **👕 الفريق الأول** — بطاقات لكل لاعب مع خصائصه الكاملة (سرعة، تسديد، تمرير، مراوغة، دفاع، قوة بدنية) ونبذة عنه، مع فلترة حسب المركز.
- **📅 المباريات** — المباريات القادمة مع عدّاد تنازلي، وآخر النتائج.
- **🛍️ المتجر** — منتجات النادي مع روابط للمتجر الرسمي.
- **🏆 عن النادي** — تاريخ النادي وأبرز بطولاته.

## 🔄 كيف يتحدث الموقع تلقائيًا؟

1. **تحديث مجدول (GitHub Actions):** ملف `.github/workflows/update-news.yml` يشغّل السكربت `scripts/update_news.py` **كل 3 ساعات** فيجلب آخر الأخبار ويحدّث `data/news.json` ويرفعه للمستودع تلقائيًا. يمكن تشغيله يدويًا أيضًا من تبويب Actions.
2. **تحديث لحظي (المتصفح):** عند فتح الموقع يحاول جلب الأخبار مباشرة من Google News RSS، ويتجدد تلقائيًا كل 10 دقائق أثناء فتح الصفحة، مع زر «تحديث الآن».

## 🚀 التشغيل والنشر

الموقع ثابت بالكامل (HTML/CSS/JS) بلا أي اعتماديات بناء.

**محليًا:**
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

**النشر على GitHub Pages:**
1. من إعدادات المستودع: **Settings → Pages → Source → GitHub Actions**.
2. ادمج هذا الفرع في `main` — سيتولى ملف `.github/workflows/deploy-pages.yml` النشر تلقائيًا مع كل تحديث (بما فيها تحديثات الأخبار المجدولة).

## 🛠️ تعديل البيانات

كل البيانات في ملفات JSON بسيطة داخل مجلد `data/` وتنعكس على الموقع فورًا:

| الملف | المحتوى |
|---|---|
| `data/players.json` | قائمة اللاعبين وأرقامهم وتقييماتهم — عدّلها بحرية |
| `data/matches.json` | المباريات القادمة والنتائج (أضف تاريخًا بصيغة ISO ليظهر العد التنازلي) |
| `data/store.json` | منتجات المتجر والأسعار ورابط المتجر الرسمي |
| `data/news.json` | يُحدَّث تلقائيًا — لا حاجة لتعديله يدويًا |
