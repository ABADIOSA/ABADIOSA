# 🦅 موقع القلعة الخضراء — النادي الأهلي السعودي

موقع جماهيري متكامل يهتم بكل ما يخص النادي الأهلي السعودي، ويتحدّث **تلقائيًا أول بأول**.

## ✨ الأقسام

- **🤖 المساعد الأهلاوي الذكي** — مساعد محادثة يعمل في المتصفح على بيانات الموقع الحية: اسأله عن أي لاعب، الترتيب، المباريات، الأخبار، البطولات الموثقة، أو اطلب توقعًا ذكيًا لنتيجة المباراة القادمة.
- **📰 الأخبار** — تُجلب آخر أخبار النادي تلقائيًا من مصادر إخبارية (Google News) وتتجدد باستمرار.
- **👕 الفريق الأول** — التشكيلة **الحقيقية** محدثة تلقائيًا من ESPN مع **صور اللاعبين والمدرب من ويكيبيديا**، وتصحيحات يدوية للانتقالات الحديثة (`departed`/`signings` في `data/players.json`)، وخصائص لكل لاعب ونبذة عربية وفلترة حسب المركز.
- **📅 المباريات** — المباريات القادمة مع عدّاد تنازلي وآخر النتائج بالشعارات الرسمية — تلقائيًا.
- **🏅 الترتيب** — جدول ترتيب دوري روشن كاملًا بالشعارات، مع تمييز صف الأهلي — تلقائيًا.
- **🎮 الألعاب** — اختبار أهلاوي (10 أسئلة)، خمّن اللاعب (من بيانات التشكيلة الحقيقية)، ولعبة ذاكرة بشعارات أندية الدوري.
- **🛍️ المتجر** — منتجات النادي مع روابط للمتجر الرسمي.
- **🏆 عن النادي** — تاريخ النادي وأبرز بطولاته.

## 🔄 كيف يتحدث الموقع تلقائيًا؟

مصادر البيانات: **واجهة ESPN العامة** (التشكيلة والمباريات والترتيب والشعارات) و**Google News RSS** (الأخبار) — بلا أي مفاتيح API.

1. **تحديث مجدول (GitHub Actions):** ملف `.github/workflows/update-news.yml` يشغّل `scripts/update_news.py` و`scripts/update_data.py` **كل 3 ساعات**، فيحدّث ملفات `data/` ويرفعها وينشرها على الموقع تلقائيًا. يمكن تشغيله يدويًا من تبويب Actions.
2. **تحديث لحظي (المتصفح):** عند فتح الموقع تُجلب المباريات والترتيب مباشرة من ESPN والأخبار من Google News، مع الرجوع للنسخة المخزنة إذا تعذر الاتصال، وتجدد تلقائي كل 10 دقائق.

## 🚀 التشغيل والنشر

الموقع ثابت بالكامل (HTML/CSS/JS) بلا أي اعتماديات بناء.

**محليًا:**
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

**النشر على GitHub Pages:**
1. من إعدادات المستودع: **Settings → Pages → Source → GitHub Actions**.
2. ادمج هذا الفرع في `main` — سيتولى ملف `.github/workflows/deploy-pages.yml` النشر تلقائيًا مع كل تحديث (بما فيها تحديثات الأخبار المجدولة).

## 🛠️ تعديل البيانات

كل البيانات في ملفات JSON بسيطة داخل مجلد `data/` وتنعكس على الموقع فورًا:

| الملف | المحتوى |
|---|---|
| `data/players.json` | طبقة الإثراء العربية: الأسماء العربية والتقييمات والنبذ — عدّلها بحرية |
| `data/store.json` | منتجات المتجر والأسعار ورابط المتجر الرسمي |
| `data/squad.json` | التشكيلة الحقيقية — **يُحدَّث تلقائيًا** من ESPN |
| `data/matches_auto.json` | المباريات والنتائج — **يُحدَّث تلقائيًا** من ESPN |
| `data/standings.json` | ترتيب الدوري — **يُحدَّث تلقائيًا** من ESPN |
| `data/news.json` | الأخبار — **يُحدَّث تلقائيًا** من Google News |
