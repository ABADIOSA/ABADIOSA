## ✨ الميزات

<div dir="rtl">

- **🌐 تكامل عبر المواقع:** أزرار ذكية "حفظ في المكتبة" و"فتح في Stremio" مباشرة داخل مواقع استكشاف الأفلام.
- **🖱️ البحث السريع بالزر الأيمن:** حدد اسم أي فيلم أو مسلسل، اضغط كليك يمين، وابحث عنه فوراً في Stremio.
- **📚 إدارة شاملة للمكتبة:** تصفح، فلترة، ترتيب، وتحديد الأعمال كمشاهَدة من نافذة الإضافة مباشرة.
- **✨ تخصيص Stremio Web** *(جديد)*: حوّل واجهة Stremio Web إلى الأسود الداكن (OLED)، قم بتغيير ألوان الواجهة، طبّق خطوط عربية جميلة (مثل خط ثمانية) على الواجهة والترجمة، واعرض تقييمات المجتمع!
- **👥 تعدد الحسابات والأفاتار**: احفظ عدة حسابات وبدّل بينها بضغطة زر، مع إمكانية تعيين شخصيات (Avatars) مميزة لكل حساب.
- **🧩 مدير الإضافات** *(جديد في v1.3.0)*: تثبيت، حذف، إعادة ترتيب، وتعديل كتالوجات إضافاتك — كل ذلك داخل الإضافة.
- **🎨 واجهة زجاجية فاخرة:** تصميم داكن مستوحى من Apple بتأثير Glassmorphism مع حركات سلسة.
- **🔗 نظام الإضافات الذكي:** اختر الإضافة المفضلة (مثل TMDB) لجلب تفاصيل الأعمال.
- **🌍 دعم ثنائي اللغة:** دعم كامل للعربية والإنجليزية مع RTL وتبديل فوري.
- **🛠 تخصيص مرن:** اختر شكل التفاصيل (بطاقة أو شاشة كاملة)، تحكم بالحجم، والمزيد!

</div>

## 🛠 طريقة التثبيت يدوياً (وضع المطور)

<div dir="rtl">

أو يمكنك تحميل الإضافة يدوياً:

1. **حمّل الإصدار الأخير:** اذهب إلى [صفحة الإصدارات](https://github.com/3-pr/StremioHub/releases) وحمّل ملف `.zip` ثم فكّ الضغط.
   *(أو استنسخ المستودع):*
   ```bash
   git clone https://github.com/3-pr/StremioHub.git
   ```
2. افتح كروم واذهب إلى `chrome://extensions/`.
3. فعّل **وضع المطور (Developer mode)** من الزاوية العلوية.
4. اضغط **Load unpacked** واختر مجلد `extension`.
5. ثبّت الإضافة في الشريط، سجّل دخولك بحساب Stremio، واستمتع!

### 🦊 Firefox
حمّل الإضافة من [صفحة الإصدارات](https://github.com/3-pr/StremioHub/releases) ثم حمّل مجلد `extension-firefox` عبر `about:debugging#/runtime/this-firefox`.

</div>

## 🔐 الأمان والخصوصية

<div dir="rtl">

- **لا نحفظ كلمات المرور:** يُستخدم حسابك مرة واحدة فقط لجلب `authKey`.
- **تخزين محلي فقط:** جميع بياناتك وإعداداتك محفوظة محلياً في `chrome.storage.local`.
- **لا تتبع:** لا نتتبع مكتبتك أو بحثك أو نشاطك إطلاقاً.

</div>

## 📋 سجل التغييرات

<div dir="rtl">

### v1.5.0 — الخطوط المخصصة والتحديث التلقائي
- ✅ **رفع خط مخصص**: إمكانية رفع وتطبيق خطك الخاص (ttf, woff, woff2) مباشرة على واجهة Stremio Web.
- ✅ **فحص التحديثات**: إضافة نظام يفحص تلقائياً وجود تحديثات لإضافاتك المُثبتة كل 24 ساعة.
- ✅ **التحديث اليدوي**: دعم تحديث الإضافات المعقدة مع الحفاظ على إعداداتك بضغطة زر.
- ✅ **استقرار Firefox**: إصلاح مشاكل إغلاق نافذة الإضافة عند محاولة رفع ملف خط في متصفح فايرفوكس.
- ✅ **الترجمة**: دعم كامل للغتين العربية والإنجليزية للميزات الجديدة.

### v1.4.2
- إصلاح تداخل الخلفية السوداء لوضع OLED مع شريط تحكم المشغل في Stremio Web
- إصلاح مشكلة عدم عمل خط "ثمانية" المخصص وإضافته بشكل برمجي صحيح
- إضافة عرض رقم الإصدار الحالي أسفل قائمة الإعدادات
- إزالة صلاحية `tabs` غير الضرورية من الإضافة لزيادة الخصوصية والأمان

### v1.4.0 — تخصيص Stremio Web وتعدد الحسابات
- ✅ إضافة سمة OLED الداكنة لـ Stremio Web لتوفير الطاقة وتحسين التباين
- ✅ تغيير الخط الأساسي لـ Stremio Web (واجهة وترجمة) مع دعم خطوط عربية
- ✅ إمكانية تغيير اللون البنفسجي الأساسي للموقع لأي لون تفضله
- ✅ حقن تقييمات المجتمع (RT, Metacritic, Letterboxd) في الموقع والإضافة 
- ✅ دعم تعدد الحسابات: حفظ أكثر من حساب والتبديل بينها فوراً
- ✅ شخصيات (Avatars): تعيين أيقونات شخصيات مخصصة لكل حساب

### v1.3.0 — مدير الإضافات
